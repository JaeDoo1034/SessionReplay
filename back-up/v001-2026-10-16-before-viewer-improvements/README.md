# v001 — 세션 뷰어 개선 전 기준 버전

백업 날짜: 2026-10-16 (Asia/Seoul)

React Flow 기반 상세 분석이 구현된 현재 작업 폴더를 보존한 스냅샷입니다. Git에 아직 커밋되지 않은 수정 사항과 새 소스를 포함합니다.

- `source/`: 소스·설정 예시·문서·참고 소스·생성된 프런트엔드 번들·이미지
- `manifest.json`: Git 기준 커밋, 파일 목록, 크기, SHA-256 검증값
- `git-status.txt`: 백업 시점의 변경 상태

소스 88개를 복사하고 각 파일의 SHA-256을 원본과 비교했습니다.

제외: 의존성(`node_modules`), Git 저장소, 기존 백업, 실제 환경변수/비밀 키, 로컬 도구 설정·캐시, 데이터베이스(`data`), 수집 세션 원본(`샘플`). `.env.example`은 포함됩니다. 실행 환경은 기존 로컬 `.env`를 사용하고 의존성은 `npm ci`로 복원할 수 있습니다.

원본 작업 폴더는 그대로 유지합니다. 복원 시 `source/` 안의 필요한 파일을 작업 폴더의 같은 경로로 복사합니다. 전체 복원 전에는 현재 상태를 다음 버전으로 먼저 보관하세요.
